### 3. Детальний аналіз параметрів мережі

| Параметр | Значення | Опис та пояснення |
| :--- | :--- | :--- |
| **Інтерфейс** | `eth0` | Основний мережевий інтерфейс комп'ютера (Intel Ethernet Connection I219-V). |
| **Тип підключення** | Дротове (Ethernet) | Дротове підключення через виту пару (Twisted Pair, стандарт IEEE 802.3, швидкість до 1 Гбіт/с). |
| **MAC-адреса** | `58:11:22:a0:5f:16` | Фізична апаратна адреса мережевої карти (**Канальний рівень / Data Link Layer, L2** моделі OSI). |
| **IP-адреса** | `192.168.2.4` | Логічна адреса хоста в локальній мережі (**Мережевий рівень / Network Layer, L3** моделі OSI). |
| **Маска підмережі** | `/24` (`255.255.255.0`) | Визначає межу між ідентифікатором мережі (перші 24 біти) та ідентифікатором хоста (останні 8 бітів). Належить до **Мережевого рівня / Network Layer, L3** моделі OSI. |
| **Gateway (Шлюз)** | `192.168.2.254` | IP-адреса домашнього роутера (шлюзу за замовчуванням), через який пакети передаються за межі локальної підмережі. |
| **Broadcast (Широкомовна адреса)** | `192.168.2.255` | Спеціальна адреса для розсилки пакетів усім пристроям поточної підмережі `192.168.2.0/24`. |
| **Hosts (Кількість та діапазон хостів)** | **254** хости (`192.168.2.1` – `192.168.2.254`) | Розрахунок: $2^{(32 - 24)} - 2 = 2^8 - 2 = 256 - 2 = 254$ доступні адреси для пристроїв (мінус адреса мережі `.0` та broadcast `.255`). Робочий діапазон: `192.168.2.1` – `192.168.2.254` (де `.254` зарезервовано роутером). |

## Завдання 2. Дослідження маршрутизації

### 1. Виконана команда
```bash
ip r
```

### 2. Результат виконання команди в терміналі
```text
default via 192.168.2.254 dev eth0 proto dhcp metric 100 
192.168.2.0/24 dev eth0 proto kernel scope link src 192.168.2.4 metric 100 
```

### 3. Аналіз протоколів та маршрутів

У виведенні команди присутні два ключові маршрути та вказано протоколи їх отримання:

1. **Маршрут за замовчуванням (`default via 192.168.2.254 dev eth0 proto dhcp metric 100`)**:
   - **Протокол:** **DHCP** (`proto dhcp`).
   - **Пояснення:** Цей маршрут (шлюз за замовчуванням `0.0.0.0/0`) було автоматично отримано від домашнього роутера (який виступає DHCP-сервером) за протоколом динамічного конфігурування вузла **DHCP (Dynamic Host Configuration Protocol)** при підключенні до мережі. Через нього комп'ютер надсилає весь зовнішній трафік (до інтернету).

2. **Локальний маршрут підмережі (`192.168.2.0/24 dev eth0 proto kernel scope link src 192.168.2.4 metric 100`)**:
   - **Протокол:** **Kernel** (`proto kernel`).
   - **Пояснення:** Цей маршрут створено безпосередньо **ядром операційної системи Linux** автоматично в момент налаштування мережевого інтерфейсу `eth0`. Він вказує, що для зв'язку з будь-яким комп'ютером у підмережі `192.168.2.0/24` шлюз не потрібен — зв'язок відбувається напряму на канальному рівні (L2) за допомогою ARP-запитів.

## Завдання 3. Знаходження публічної IP-адреси

### 1. Виконана команда

### 2. Результат виконання команди в терміналі
```text
81.205.183.154
```

*(IPv6 варіант: `2a02:a45f:864f:0:b1cc:246:eb58:78ad`)*

---

### 3. Порівняння та аналіз локальної та публічної адрес

* **Локальна IP-адреса:** `192.168.2.4`
* **Публічна IP-адреса:** `81.205.183.154`

#### 1. Чи однакові адреси?
**Ні, вони різні.**

#### 2. Чому вони різні та яку роль відіграє домашній роутер?
* **Приватна (локальна) адреса `192.168.2.4`:** належить до зарезервованого діапазону приватних адрес згідно зі стандартом **RFC 1918** (`192.168.0.0/16`). Такі адреси дійсні лише всередині локальної мережі (LAN) будинку чи офісу і взагалі не маршрутизуються у глобальній мережі Інтернет.
* **Публічна (біла) адреса `81.205.183.154`:** є глобально унікальною в усьому світі. Її видає інтернет-провайдер (ISP) на зовнішній (WAN) порт домашнього роутера.
* **Роль домашнього роутера:**
  1. Домашній роутер виступає шлюзом і використовує механізм **NAT (Network Address Translation)**, а точніше його різновид **PAT / NAPT (Port Address Translation)**.
  2. Коли ПК або смартфон надсилає запит в інтернет, роутер перехоплює вихідні IP-пакети, змінює локальну IP-адресу джерела (`192.168.2.4`) на свою власну зовнішню публічну IP-адресу (`81.205.183.154`), а також підставляє вільний порт відправника.
  3. Роутер фіксує цю відповідність у своїй **таблиці трансляцій NAT**. Коли надходить відповідь із сервера в інтернеті, роутер за номером порту визначає, якому саме пристрою в домашній мережі вона призначена, замінює публічну адресу на локальну і пересилає пакет отримувачу.
  4. Таким чином, домашній роутер дозволяє всім домашнім пристроям одночасно користуватися інтернетом через одну публічну адресу IPv4, вирішуючи проблему глобального дефіциту адрес IPv4 та забезпечуючи базовий захист пристроїв від прямого доступу з інтернету.
